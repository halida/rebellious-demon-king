# 网络小说离线下载工具箱

> 从下载《反叛的大魔王》（1523 章 / 805 万字 / 0 失败）的实操中提炼出来的可复用工具与经验。
> 面向"把已购/免费可读的长篇小说变成自己的离线 TXT"这一件事。

---

| 文件 | 作用 |

## 60 秒上手

```bash
# 1) 探测站点结构（不抓正文）
python3 下载小说.py --probe "https://站点/分类/书号/"

# 2) 先抓 3 章验证
no_proxy='*' python3 下载小说.py --book "https://站点/分类/书号/" \
        --limit 3 --workers 2 --outdir 原文 --title "书名"

# 3) 全量（可随时中断，重跑即续传）
no_proxy='*' python3 下载小说.py --book "..." --workers 3 --outdir 原文 --title "书名" --author "作者"

# 4) 体检
python3 校验完整性.py --dir 原文
```

> `no_proxy='*'` = 绕过环境代理直连（本次实测直连比走代理快数倍，且能绕开共享代理的限流）。

```
├── <书名>-章节索引.txt      速查表：序号 \t 章节id \t 标题 \t 字数
├── 章节/<id>.txt            单章文件
└── missing.txt              缺失章清单（正常应为空）
```

## 三条最重要的经验

1. **先验源再抓**：镜像站常是残缺的（本次那本就在最激烈的战斗中戛然而止，缺了 60 多章和结局）。先比章数、比对末章名。
2. **能续传就别重来**：边抓边落盘 + 原子写 + 已存在即跳过。脚本崩了不用重跑。
3. **成品必须体检**：章数、短章、分页残留、重复、首末章名——五项全过再宣布完成。

## 版权与边界

下载文本仅供**个人离线阅读**；作品版权归原作者与连载平台，请勿二次分发或商用。
优先使用官方 APP 的「下载/离线缓存」功能——既支持作者，也省去所有技术折腾。
