# 新书下载 · 操作清单

> 复制这份清单，每下一本书就照着走一遍。全程约 5–90 分钟（取决于书的大小与站点速度）。

---

## 阶段 0 · 选源（别跳过这步）

- [ ] 查官方平台（起点/QQ阅读/番茄/晋江…）是否存在本书
  - [ ] 记录：官方章数、最后更新时间、是否完本
  - [ ] 官网免费章读到哪一章？（决定后面还需不需要第三方源）
  - [ ] 已订阅的话 → 直接用 **APP「下载/离线缓存」**（最合规、最省事）
- [ ] 若需第三方镜像：**先验证完整性**
  - [ ] 镜像目录章数 vs 官方目录条数 → 差很多 = 残缺，换源
  - [ ] 镜像末章是不是"终章/后记/完本感言"？→ 不是 = 缺结局，换源
  - [ ] 镜像首章是不是"第一章/序章"？
- [ ] 选定 1–2 个候选镜像，记录 URL

## 阶段 1 · 探测结构

- [ ] `python3 工具/下载小说.py --probe "<目录页URL>"`
- [ ] 记录：书籍前缀 / 目录总章数 / 首章名 / 末章名 / 正文容器命中情况
- [ ] 末章名合理？（若停在半截剧情 → 换源）

## 阶段 2 · 小样本试抓

- [ ] `--limit 3 --workers 2` 抓 3 章
- [ ] 人工读第 1 章：正文完整？段落正常？
- [ ] `grep -c "第(1/.*)页" 原文/*全书.txt` → 应为 **0**
- [ ] 若章节被截断 → 看 `<a id="next1">` 的真实 href 规律，改翻页正则

## 阶段 3 · 全量抓取

- [ ] `no_proxy='*' python3 工具/下载小说.py --book "..." --workers 3 --outdir 原文 --title "书名" --author "作者"`
- [ ] 直连不通 → 去掉 `no_proxy='*'` 走代理试
- [ ] 中断了就重跑同一条命令（自动续传）
- [ ] 日志另存：`> 抓取日志.txt 2>&1`（**别用 `| tail`**，会缓存看不到进度）

## 阶段 4 · 成品体检

- [ ] `python3 工具/校验完整性.py --dir 原文`
- [ ] 章数 = 索引章数 = 单章文件数 ✔
- [ ] 可疑短章逐个确认（公告 vs 抓断）✔
- [ ] 分页标记残留 = 0 ✔
- [ ] 首章 / 末章名正确 ✔
- [ ] 总字数量级合理 ✔
- [ ] 与官方标题清单比对（可选 `--ref`）：章数一致 ✔

## 阶段 5 · 收尾

- [ ] 合并 TXT 头部含书名 / 作者 / 来源 / 版权声明 ✔
- [ ] 生成 `章节索引.txt` ✔
- [ ] `missing.txt` 为空（否则补抓：`--rounds 5`）✔
- [ ] 写一份 README 说明生成方式与来源 ✔
- [ ] 顺手做一份**知识拆解**（剧情 / 世界观 / 作者风格 / 理论）——那是这本书真正的价值

---

## 应急速查

| 症状 | 先试 |
|---|---|
| 大量超时 | 去代理直连 `no_proxy='*'`；或 `--use-proxy` |
| 抓到 0 章 | `--probe` 看正文容器；对比浏览器源码 |
| 目录只有几十章 | 目录分页模式不同 → 翻页看真实 URL |
| 章节半截 | 翻页规则不对 → 看 `id="next1"` 的 href |
| 跑到一半卡住 | 降并发到 1–2，等 5 分钟再试（多为站点限流） |
| 合并文件没生成 | 看脚本末尾的写文件段；先确认单章文件已落盘 |
| 中途失败没进度 | 脚本要"边抓边落盘"；重跑同命令即可续传 |

---

## 合规提醒（每次都看一眼）

- 下载文本**仅供个人离线阅读**，不二次分发、不转售、不商用。
- **优先官方 APP 离线缓存**——既支持作者，又不折腾。
- 引用原文要短、注明出处。
- 低并发、低频率；只抓自己真正要读的那一本。
