## 关键技术备忘

- **听雨中文网正文不在 HTML 里**：前端 `chapter.js` 通过 `POST /home/index/ajaxchapter` 取文，参数 `id=29668&eKey=<hash>&cid=<chapter_id>&basecid=<chapter_id>`，翻页再带 `nextpage&pagehash`；也可以直接访问 `<id>_N.html` 的转码分页。
- **代理限流**：走环境代理 `proxy.llj.click:8080` 时会随机出现 SSL 握手超时（约 20 分钟一片），**绕过代理直连即恢复**——不是站点封禁。
- **章节 id 与起点发布顺序有错位**（1167—1169 重号、1366 处重新起编"诸神的黄昏（1）"），因此报告中一律用"卷次 + 篇目锚点"定位，不逐章纪年。
- **听雨站会做同音字替换防抄**（如"成默"→"我"），研究时需还原。
