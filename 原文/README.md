## 生成方式

由本项目 `工具/` 下的脚本生成：

```bash
# 全书（推荐：Cookie 会话 + 限速 + 断点续传）
no_proxy='*' python3 工具/抓取全书-稳健版.py --workers 3

# 全书（旧版，无续传）
python3 工具/抓取全文.py --workers 6

# 仅官方免费章节 1-135（起点/QQ阅读 官方首发）
python3 工具/抓取正文.py --start 1 --end 135

# 通用下载器（任意站点，自动探测结构）
python3 工具/下载小说.py --book "<目录页URL>" --outdir 原文 --title "书名"
```

- `抓取全书-稳健版.py`：先抓目录页 `index_1..16` 收集全部章节链接（按数字 id 升序 = 书中顺序），再逐章抓正文并自动翻页（`_2` / `_3`），最后合并成 TXT；已存在的单章自动跳过，可中断续跑。
- `抓取全文.py`：功能相同但不支持续传。
- `抓取正文.py`：只走起点/QQ阅读官方章节页，产出官方**免费发布**的第 1—135 章（免费截止于 2017-12-08 上架当章）。
- `下载小说.py`：通用版，换一本书直接用（见 [工具/下载经验手册.md](../工具/下载经验手册.md)）。

> ⚠️ 网络提示：本机走环境代理 `proxy.llj.click:8080` 访问小说01会出现 SSL 握手超时，**绕过代理直连（`no_proxy='*'`）即可正常抓取**。
